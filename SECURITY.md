# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public GitHub issue.

Until a private security contact is published for this repository, report a
potential vulnerability privately to the repository owner through GitHub
Direct Message or the repository's private vulnerability reporting feature.
Include a clear description, reproduction steps, affected version or commit,
and any suggested mitigation.

Please avoid including personal documents or sensitive PDF content. Remove or
redact private data from reproduction materials.

## Scope

Reports may include unsafe file handling, unexpected network access, code
execution, installer behavior, dependency vulnerabilities, or accidental
exposure of document contents.

Marklift is designed to process PDFs locally and does not intentionally use
accounts, telemetry, uploads, or runtime network calls.
