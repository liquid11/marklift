# Marklift 1.0.1 Release Verification

Date: 2026-07-24

Target: Windows 10/11 x64

Python: 3.11.9

## Release purpose

Marklift 1.0.1 is a patch release that restores branded and action icons in the
packaged Windows application. It also strengthens packaging validation, Windows
version metadata, and the UI test lifecycle.

The UI suite now waits for the conversion thread itself to finish before a test
continues. This removes a Qt shutdown race that previously appeared only when
multiple UI tests ran sequentially.

## Distribution note

The executable and installer are not Authenticode-signed. Windows SmartScreen
may therefore show an additional warning. A trusted code-signing certificate is
still recommended for broad distribution; this repository does not include a
private signing key.

## Installed-application verification

The final installer was exercised through its explicit `/CURRENTUSER` override
in an isolated temporary directory. Installation completed with exit code 0,
and the installed `Marklift.exe` SHA-256 exactly matched the packaged
application listed above.

The installed application then passed launch, icon, folder-intake, English OCR,
damaged-file isolation, source-preview, and two-file batch-save checks. The
saved OCR Markdown contained `MARKLIFT OCR E2E 101` and referenced its generated
PNG asset. The isolated uninstaller completed with exit code 0 and removed the
test installation, current-user shortcuts, and uninstall registration without
modifying the existing all-users installation.
