# Marklift 1.0.1 Release Verification

Date: 2026-07-24  
Target: Windows 10/11 x64  
Python: 3.11.9

## Release purpose

Marklift 1.0.1 is a patch release that restores branded and action icons in the
packaged Windows application. It also strengthens packaging validation, Windows
version metadata, and the UI test lifecycle.

The UI suite now waits for the conversion thread itself to finish before a test
continues. This removes a Qt shutdown race that previously appeared only when
multiple UI tests ran sequentially.

## Distribution note

The executable and installer are not Authenticode-signed. Windows SmartScreen
may therefore show an additional warning. A trusted code-signing certificate is
still recommended for broad distribution; this repository does not include a
private signing key.

## Final publication gate

Before publication, upgrade the existing Windows installation with the final
installer, launch the installed copy, and repeat the launch/icon/OCR smoke test.
